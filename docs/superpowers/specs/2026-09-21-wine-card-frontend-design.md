# Фронтенд: сканирование и карточка вина

Дата: 2026-09-21. Mobile-first UI внутри `web/` (Nuxt), стилистика vino-svoe.ru.

## Экраны

- `/` — сканирование: «Сфотографировать этикетку» (камера) / «Выбрать из галереи», превью, индикатор поиска. После ответа — переход на карточку Top-1 (или экран «не найдено»).
- `/wine/:slug` — карточка: фото, название (Playfair Display), винодельня, характеристики (регион, сорт, категория и цвет, цвет), описание; блок кандидатов по статусу поиска; лента «Похожие вина».
- Прямой заход на `/wine/:slug` (без поиска) — карточка + «Похожие вина».

## Статус распознавания (решает бэкенд, `/v1/search` → `status`)

| status | условие | UI |
|---|---|---|
| `confident` | score₁ ≥ `NOT_FOUND_SCORE` и margin ≥ `CONFIDENCE_MARGIN` | карточка; «Не то вино?» свёрнуто |
| `uncertain` | score₁ ≥ `NOT_FOUND_SCORE`, margin мал | плашка «Возможно, это»; варианты раскрыты |
| `not_found` | score₁ < `NOT_FOUND_SCORE` | «Точного совпадения нет в каталоге» + «Похожие вина» (Top-5) |

По умолчанию `CONFIDENCE_MARGIN=0.03`, `NOT_FOUND_SCORE=0.72` (из синтетики: средний score₁ 0.78; вина вне каталога на публичных фото — 0.69–0.74). Пороги предварительные, калибруются на размеченных фото.

## API (добавляется)

- `/v1/search`: поле `status`.
- `GET /v1/wines/:slug/similar?limit=8` → `[{slug, name, winery, score, image_url}]` — ближайшие по эмбеддингу эталона (без самого вина).
- `/v1/search` кандидаты получают `image_url`.
