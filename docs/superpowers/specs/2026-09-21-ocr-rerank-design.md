# OCR-переранжирование Top-10

Дата: 2026-09-21. Локальный EasyOCR (ru + en, GPU); облачный OCR (Yandex Vision) — возможная замена за тем же интерфейсом.

## Поток

```
web: фото ─► ml POST /analyze ─► {embedding, ocr: [{text, conf, h}]}
     pgvector: Top-10 по визуальному скору (+ поля вина: name, winery, grapes, category)
     ─► ml POST /rerank {ocr, candidates} ─► кандидаты с visual/text/final скором, отсортированы по final
     ─► Top-5, margin и status — по final
```

Логика сравнения текста — одна реализация на Python (`ml/wine_ml/text_match.py`), её используют и сервис, и `evaluate.py`.

## Замер EasyOCR на публичных фото

0.3–0.6 с на фото (1280 px). Ошибки распознавания: «МУСКАТЕАЬ», «БЕАЫЙ», «МАССАНАРА»; в кадр попадает текст соседних бутылок.

## Сравнение текста

1. **Нормализация**: нижний регистр, ё→е, транслитерация кириллицы в латиницу (как в `catalog.py`), токены `[a-z0-9]+`, длина ≥ 3 или год.
2. **Токены кандидата**: name, winery, grapes, category + токены slug (уже латиница).
3. **Нечёткое совпадение**: токен кандидата найден, если есть OCR-токен с нормированным сходством Левенштейна ≥ 0.8 (`muskatea`↔`muskatel` 0.875; `muskat`↔`muskatel` 0.75 — не совпадение).
4. **Веса «внутри Top-10»**: токен, который есть у всех кандидатов («massandra»), ничего не различает — вес `log((K + 1) / (df + 0.5))`, df — у скольких кандидатов из K он есть. Вес OCR-токена — его уверенность.
5. **text_score** = Σ весов найденных токенов кандидата / Σ весов всех его токенов (доля «подтверждённого» названия), 0…1.
6. **Противоречия**: группы слов — цвет (белое / красное / розовое / оранжевое), сахар (брют / экстра брют / сухое / полусухое / полусладкое / сладкое), год (2000–2030). Если на фото прочитано значение группы, а у кандидата есть другое значение той же группы и нет прочитанного — штраф.
7. **final = visual + α · text_score − β · conflicts**; α, β подбираются на подвыборке синтетики, проверяются на полной.
8. `not_found` решается по визуальному скору Top-1 (текст не должен «вытягивать» вино, которого нет в каталоге); `margin`/`confident` — по final.

## Конфиг

`OCR_ENABLED` (web, по умолчанию 1), `RERANK_K=10`, `OCR_ALPHA`, `OCR_BETA` (ml). Выключение OCR возвращает поведение предыдущего этапа.

## Оценка

`evaluate.py --ocr`: OCR запросов кэшируется (как эмбеддинги); переранжирование той же функцией. Сравнение с этапом 2 на тех же запросах; отдельно near_duplicates. Latency `/v1/eval/predict` < 1.5 с.
