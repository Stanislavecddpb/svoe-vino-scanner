# CV: двойники в каталоге и несколько векторов на вино

Дата: 2026-09-21. В рамках CV baseline (без OCR и дообучения).

## Проблемы (из анализа индекса и ошибок)

1. **Двойники**: 67 эталонов имеют эталон другого вина с косинусом ≥ 0.99 — по сути одно и то же фото (напр. Az Abrau «Баяншира» и «Мадраса»). Такие пары не различимы по изображению в принципе.
2. **Масштаб**: полевое фото — крупный план этикетки, эталон — бутылка целиком. Среди ошибок только ~половина имеет верный ответ в Top-5.

## Решение

### C. Двойники

- `ml/scripts/find_twins.py` → `data/catalog/twins.csv` (`group, slug, name, winery, max_cos`): связные компоненты графа «косинус полного вида ≥ `--threshold` (0.99)».
- В индексе остаются (у сервиса есть шанс угадать; удаление дало бы гарантированную ошибку).
- `evaluate.py` считает основную метрику **без** двойников, двойники — отдельной строкой. Это соответствует заданию: «проблемные записи исключить из проверки».

### A. Несколько видов (views) на вино

- Для каждого эталона: `full` (бутылка целиком, как сейчас) + зоны этикетки, вырезанные по bbox бутылки на всю ширину:
  - `label_mid` — 30–70 % высоты бутылки;
  - `label_low` — 45–95 % высоты.
  Зоны шире и расположены иначе, чем кроп синтетического теста (35–55 % + 30–45 %), чтобы не подгонять индекс под тест; остаточная оптимистичность отмечается в отчёте.
- БД: `wine_embeddings` получает колонку `view text NOT NULL DEFAULT 'full'`, PK `(slug, model, view)`. Миграция `db/migrations/002_views.sql` для существующих баз; `db/init.sql` — сразу новая схема.
- Поиск (web `VectorEngine`, `evaluate.py`): score вина = **максимум** по его видам; Top-K по винам.
- «Похожие вина» и поиск двойников — только по `full`.
- `build_index.py --views full,label_mid,label_low` (по умолчанию все три).
- `evaluate.py --views ...` — сравнение «было / стало» на одних и тех же синтетических запросах; эмбеддинги запросов кэшируются в `reports/cache/` (второй прогон — секунды).

## Критерии

- Сравнение baseline (`--views full`) и multi-view на одной синтетике, без двойников: Top-1, Top-5, margin.
- 3 публичных фото: Массандра «Мускатель белый» — позиция в Top-5 не хуже #2.
- Latency `/v1/eval/predict` < 1 с (запрос по-прежнему один эмбеддинг; SQL по ~6k строк).
- Все тесты зелёные; контракт API без изменений.
