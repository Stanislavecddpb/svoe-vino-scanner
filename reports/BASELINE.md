## Выводы

1. Пайплайн технически работает end-to-end, контракт кейсодержателя соблюдён, SLA с запасом.
2. Кандидаты адекватные: модель находит тот же сорт/производителя/дизайн; для вин вне каталога отрыв маленький — это можно использовать для ответа «не найдено / похожие вина».
3. Точности baseline недостаточно для цели 90%: Top-1 ≈ 60%, Top-5 ≈ 81% на синтетике. Главные ошибки — near-duplicates (одна серия этикеток) и разрыв «крупный план этикетки vs студийное фото бутылки».
4. Следующие шаги по эффекту: OCR-переранжирование Top-5 (год, «белый/розовый», название); несколько векторов на вино (бутылка + зона этикетки); порог «не найдено» по score/margin; дообучение на 4060.
